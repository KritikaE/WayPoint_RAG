# WayPoint RAG

A Retrieval-Augmented Generation (RAG) system for answering questions about Visa dispute and chargeback policies.

## Features

- Visa dispute policy PDF ingestion
- Semantic search with ChromaDB
- Document reranking
- Gemini-powered answers
- Grounded responses using Visa evidence
- Source information with conditions and printed pages
- FastAPI REST API
- Swagger API documentation
